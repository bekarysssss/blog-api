## Генерация данных (Seed команда)

Для быстрого заполнения базы данных пользователями, постами и комментариями используйте команду `seed`.

**Пример использования:**
`python manage.py seed --clear --users 20 --posts 100 --comments 500`

**Аргументы:**
* `--users`: Количество пользователей (по умолчанию 20)
* `--posts`: Количество постов (по умолчанию 100)
* `--comments`: Количество комментариев (по умолчанию 500)
* `--clear`: Удалить все старые данные перед генерацией новой партии
